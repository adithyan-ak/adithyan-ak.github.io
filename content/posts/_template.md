Open with the finding, system boundary, or question the research resolves.

## First evidence-led section

Build the argument from reproducible evidence. Use descriptive headings because
they become stable table-of-contents anchors.

### Supporting detail

Use fenced code blocks with a language identifier, concise tables, and images
with useful alt text.

> Reserve blockquotes for a finding, constraint, or analyst note worth isolating.

## Consequence and remediation

Close with what changes for builders, defenders, or researchers. Link primary
sources and the relevant repository, advisory, or reproduction material.
